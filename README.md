# PropScout - AI

Sistema de identificacion de casas en venta para inmobiliarias

## Caracteristicas

El sistema por medio de una camara o webcam identifica por medio de los letrero de "Se Vende Casa" que casas esta en venta, guarda datos de la casa como fotografia y datos de ubicacion esto para gente que trabaja en una inmobiliaria y que este conduciendo por la zona

## Fases del Proyecto

### Primera Fase

Proyecto en una laptop, el proyecto estara y se entrenara inicialmente en una laptop y una camara para revisar los datos

### Segunda Fase

El proyecto pasara a ejecutarse en un microcontrolador o minipc para mas portabilidad

### Ultima fase

Si es posible se creara todo el proyecto en un solo Componente para mayor portabilidad
